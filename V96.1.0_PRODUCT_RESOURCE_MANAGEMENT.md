# OFFSCRPT V96.1.0 — Product Resource Management

## Resource model
Product resources are stored in the existing `digitalProductFiles` collection. Existing uploaded files are normalized as `resourceType=upload`; creator-added links use `resourceType=external`.

## Creator controls
Creators can rename uploaded resources, archive/restore resources, add external HTTPS links, and update or archive/restore those links. Ownership is verified server-side against the canonical product creator.

## Names
Resource display names are limited to 60 characters server-side. Storage object names and paths are not changed by renaming.

## Buyer entitlement
Protected uploaded files remain behind the existing entitlement/download flow. Archived resources remain visible to purchasers whose purchase predates the archive timestamp, preserving historical access.

## External links
External links are never exposed from the public product payload for protected products. Purchased access is checked server-side by `openExternalResource`.

## Firestore
Affected marketplace queries use equality-only base reads with server-side filtering/sorting to avoid unnecessary composite-index dependencies.

## Manual payouts
V94 manual creator payout mode remains active; no new Razorpay Route transfer is invoked.
