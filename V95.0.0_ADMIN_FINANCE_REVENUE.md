# OFFSCRPT V95.0.0 — ADMIN FINANCE + REVENUE INTELLIGENCE

V95 adds a server-authoritative reporting/intelligence layer over V90 verified sales, V93 financial allocations, and V94 ledger/payout/refund records.

## Included
- Master Admin Finance Intelligence dashboard
- KPI summary and comparison periods
- revenue trend series
- commission, creator-net, payout and refund series
- creator/product/order/payout/refund drilldowns
- creator liability reporting
- finance health/reconciliation checks
- CSV exports
- server-side authorization and aggregation
- exact paise-safe aggregation
- historical stability: reports do not rewrite V93/V94 source records

## Scope
V95 is reporting/analytics. V94 remains authoritative for creator balances and payout execution. V95 does not directly create Route transfers or mutate balances.

## Validation
Run `npm run check:v95-finance` and the complete `npm run verify` chain.
