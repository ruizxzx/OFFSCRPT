## Razorpay credential troubleshooting
If checkout creation returns a Razorpay authentication error, ensure `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` are the matching pair from Razorpay **Test Mode**, entered into the same Vercel environment with no surrounding quotes or whitespace. Set `RAZORPAY_ENVIRONMENT=test` for test credentials and redeploy after changing variables. Never expose the Key Secret in frontend variables.
