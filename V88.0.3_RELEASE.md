# V88.0.3 RELEASE

## Product Media + Storefront UX

- Product preview/gallery images now use the existing OFFSCRPT public media R2 pipeline.
- Creator Studio supports multi-image product galleries, cover selection and image removal.
- Public product pages now provide a large gallery carousel with thumbnails and previous/next controls.
- Creator storefront product cards render cover imagery when available.
- Public commerce product projections include thumbnail/gallery/subtitle/subtype metadata.
- Protected digital product files remain separate from public preview media and still require `R2_PRODUCT_BUCKET_NAME`.
