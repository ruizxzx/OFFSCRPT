# V96.1.0 — Mobile Purchase Position Fix

## Required mobile order

On product pages below the mobile breakpoint, the order is:

1. Main product image
2. BUY THIS PRODUCT
3. Gallery thumbnails (when present)
4. Product details
5. Creator
6. Customer reviews
7. Creator products
8. Related products

The purchase panel is a sibling grid item and is placed immediately after the main image in DOM order. On desktop it is explicitly positioned in the right column and remains sticky without changing the desktop two-column presentation.

## Regression invariant

The purchase panel must never appear before the main product image on mobile and must never be pushed below product details/reviews/related products.
