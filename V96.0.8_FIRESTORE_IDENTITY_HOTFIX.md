# V96.0.8 — Firestore Query + Public Identity Hotfix

## Fixed
- Product-page published review loading no longer requires the productId+status+createdAt composite at runtime.
- Creator trust/product loading no longer requires creatorId+updatedAt at runtime.
- Creator payout listing no longer requires creatorId+createdAt at runtime.
- Public post/article author refresh no longer reads another user's private `/users/{uid}` document.
- Existing Firestore composite indexes remain declared for production scaling; code paths are resilient before index deployment.

## Deployment
Deploy the application/API and `firestore.indexes.json`.
