# OFFSCRPT V92.0.0 — Creator Onboarding + Razorpay Route

V92 adds the seller identity and Razorpay Route Linked Account foundation on top of the existing V90 payment system.

## Scope
- Canonical `creatorCommerceProfiles/{creatorId}` seller profile.
- Server-side Linked Account creation through Razorpay Route `POST /v2/accounts`.
- Seller status/health and provider account mapping.
- Creator onboarding UI in Creator Dashboard → Seller Account.
- Marketplace product activation requires an active seller.
- Creator/admin status refresh and lifecycle controls.
- Route webhook verification and replay-safe processing.
- Future compatibility for V93 commission and V94 balance/payout work.

## Provider boundary
OFFSCRPT stores only the provider account mapping and operational status needed for marketplace logic. KYC/banking credentials are not stored in OFFSCRPT by this feature. Razorpay handles the regulated payment-account/KYC boundary.

## Environment
Reuse V90 Razorpay variables:
- `RAZORPAY_KEY_ID`
- `RAZORPAY_KEY_SECRET`
- `RAZORPAY_ENVIRONMENT`
- `RAZORPAY_API_VERSION`
- `RAZORPAY_WEBHOOK_SECRET`
- `OFFSCRPT_PRODUCTION_URL`

## Endpoints
The Vercel Commerce API remains consolidated. Actions include:
- `createSeller`
- `getSeller`
- `refreshSeller`
- `enableSeller`
- `disableSeller`
- `adminListSellers`
- `adminSetSellerStatus`
- `razorpayRouteWebhook`

## Seller lifecycle
`not_started → creating_account → created/pending_review → active`

Provider suspension maps to an OFFSCRPT suspended state. Disablement stops new selling but preserves historical orders and the provider mapping.

## V93/V94 boundary
V92 does **not** calculate commissions or automatically transfer money to creators. V93 defines the profit-cut rules and V94 defines balances/payouts. The `razorpayAccountId` mapping is the foundation those versions will consume.

## Razorpay references
Razorpay currently documents Linked Account creation at `POST /v2/accounts`, with details including business email/phone, legal/customer-facing business name, business type, reference ID, profile and contact information. Linked Accounts receive unique `account_id` values and have provider status such as `created` or `suspended`.
