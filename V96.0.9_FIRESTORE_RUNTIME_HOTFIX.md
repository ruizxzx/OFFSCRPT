# OFFSCRPT V96.0.9 — Firestore Runtime + Product Render Hotfix

This patch addresses runtime failures reported after V96.0.8 deployment.

## Fixes
- Removed composite-index-dependent creator ledger balance query.
- Removed composite-index-dependent creator payout query paths.
- Removed composite-index-dependent review eligibility and own-review lookup paths.
- Made ProductReviewsSection rating rendering null/undefined-safe.
- Reduced admin notification subscription attempts to users authorized as platform moderators, preventing client permission noise for normal/master-admin-only sessions when Firestore rules do not grant direct collection access.
- Preserved manual creator repayment mode and V93/V94 financial boundaries.

## Important
This release does not remove or weaken Firestore security rules and does not make private user documents public.
