# OFFSCRPT V92.0.0 RELEASE

## Creator Onboarding + Razorpay Route

V92 introduces OFFSCRPT seller identity and Razorpay Route Linked Account connectivity while preserving the V90 payment and V91 order/download architecture.

### Added
- Seller onboarding panel in Creator Dashboard.
- Server-side Razorpay Route Linked Account creation.
- Canonical seller/provider mapping via `creatorCommerceProfiles`.
- Seller eligibility gate for marketplace product activation and checkout.
- Creator seller status refresh/enable/disable flows.
- Master Admin seller management and status controls.
- Route webhook signature verification, deduplication and safe provider-state synchronization.
- V92 validation and documentation.

### Deferred by design
- Commission engine (V93)
- Creator balances/payouts (V94)
- Full finance console (V95)

### Security
- Razorpay secrets remain server-only.
- Provider account IDs are never accepted as authoritative client input.
- Seller status and eligibility are server-authoritative.
- Historical Commerce orders/payments/entitlements are preserved.
