# V96.0.6 Release

## Added
- Manual UPI creator payout mode
- Creator UPI/mobile/email payout profile
- Admin approve/reserve + manual payment recording flow
- Manual payment reference and note tracking
- Explicit platform settlement mode on new checkout orders/payments

## Changed
- New creator selling no longer depends on Razorpay Route linked accounts
- Checkout no longer requires a Route account
- New creator payouts never invoke Route transfer creation
- Creator and admin payout UIs now show manual settlement data

## Compatibility
- Existing V93/V94 ledger and payout collections remain canonical
- Historical Route payouts are not rewritten

## Known limitation
Production typecheck/build must still be validated in an environment with a complete dependency installation.
