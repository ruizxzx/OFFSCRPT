# OFFSCRPT V93.0.0 Release

## Release
`V93.0.0 — COMMISSION + PROFIT-CUT ENGINE`

## Added
- Versioned product/creator/global commission rules.
- Exact INR commission calculations using paise and BigInt arithmetic.
- Canonical `commerceFinancialAllocations` sale records.
- V93 commission snapshots on `creatorRevenue`.
- Idempotent commission allocation keyed to canonical order identity.
- Razorpay refund webhook verification and financial reversal allocations.
- Full/partial refund protection and cumulative refund invariants.
- Creator EARNINGS panel.
- Master Admin commission rules, simulator, financial summary, order lookup and reconciliation UI.
- V93 Firestore protections and targeted indexes.
- V93 validation script wired into `npm run verify`.

## Intentionally not included
- Creator wallet / withdrawable balance.
- Automatic Razorpay Route transfers.
- Payout scheduler.
- Full finance dashboard / revenue graph system.
- Tax filing automation.

## Operational requirement
A production commission rule must be explicitly configured by Master Admin. V93 does not assume a default percentage.
