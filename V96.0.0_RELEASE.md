# V96.05 Release

## Added
- server-authoritative reviews with verified-purchase provenance
- review aggregates and public review API
- user marketplace reporting
- moderation cases, queue, actions, assignment and audit
- deterministic trust signals
- trust health and aggregate validation/rebuild tooling
- responsive review/report/admin surfaces

## Changed
- marketplace purchase/publication paths now honor V96 moderation state
- creator seller/product records carry safe trust/moderation defaults
- fixed legacy `fsRunQueryAdvanced` call-shape incompatibility so older V94/V95 object-style and positional queries share one implementation

## Security
- V96 collections are denied to direct Firestore clients
- review verification, moderation, aggregate updates, ownership and permissions are server authoritative

## Compatibility
V90–V95 architecture is preserved; V96 attaches trust data beside, not inside, the financial stack.

## Migration
No destructive migration is required. Review aggregates can be backfilled with the bounded V96 script.

## Testing
Run `npm run check:v96-trust` plus the existing V90–V95 validators and normal typecheck/build commands.

## Known limitations
Integrity/admin scans are bounded to protect request cost; large installations should add cursor-driven reporting/backfill later.
