# OFFSCRPT V96.0.6 — Manual Creator Payouts

## Purpose
Razorpay Route creator transfers are disabled. Customer checkout payments remain collected by OFFSCRPT. Creator earnings continue through the canonical V93/V94 allocation and ledger flow, while creator repayments are handled manually by an authorized admin.

## Creator payout details
Creators provide and may update:
- UPI ID
- Mobile number
- Email

These values are stored on the private seller profile and snapshotted onto payout requests for authorized admin settlement.

## Payout lifecycle
`creator request → admin approve/reserve → admin pays externally → admin records payment reference → processed`

The manual payment confirmation creates the canonical V94 payout debit and marks the payout reconciled. No Razorpay Route transfer is created.

## Financial boundary
V96.0.6 does not rewrite V93 allocations, V94 balances, or historical payout records. Legacy Route payout reconciliation remains available only for historical records carrying Route transfer IDs; new payouts are manual.
