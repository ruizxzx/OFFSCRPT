# V88.0.4 RELEASE

## Dedicated Digital Product R2 Credentials

- Digital product storage now uses dedicated credentials independent from public media storage.
- Required Vercel variables: `R2_PRODUCT_BUCKET_NAME`, `R2_PRODUCT_ACCOUNT_ID`, `R2_PRODUCT_ACCESS_KEY_ID`, `R2_PRODUCT_SECRET_ACCESS_KEY`, `R2_PRODUCT_S3_ENDPOINT`.
- Existing public-media variables remain untouched.
- Digital product presigned PUT/HEAD operations use only the product-specific R2 configuration.
- Missing configuration errors list the exact product-storage variables required.
