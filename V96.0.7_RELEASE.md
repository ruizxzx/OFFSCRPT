# OFFSCRPT V96.0.7 — Firestore Index Hotfix Release

## Fixed
- Product page Firestore `FAILED_PRECONDITION` caused by missing/undeployed review composite filters.
- Product-page creator trust query no longer requires `creatorId + status + visibility + updatedAt`.
- Public review query no longer requires `moderationStatus` as a Firestore index filter.
- Own-review lookup avoids an unnecessary `reviewerId + productId + updatedAt` composite.
- Added required reviewer/report abuse-limit indexes.
- Retained exact Firebase-reported composite indexes for compatibility.

## Compatibility
Manual creator repayment mode remains active. V90–V96 architecture is preserved.

## Validation
Static/source validation must pass before release. A production Vite build is only considered verified when dependencies install successfully and `npm run build` completes.
