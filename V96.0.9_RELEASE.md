# OFFSCRPT V96.0.9 RELEASE

## Fixed
- Product page render crash caused by undefined review aggregate `averageRating`.
- Review eligibility requests that could hit composite-index ordering.
- Own-review lookup that could hit composite-index ordering.
- Creator vendor-balance query requiring `creatorId + effectiveAt`.
- Creator payout query requiring `creatorId + createdAt`.
- Admin payout query ordering dependencies for filtered creator/status queries.
- Unnecessary admin notification Firestore subscription permission errors.

## Compatibility
V90–V96 architecture retained. Manual creator repayment remains the active payout mode.

## Runtime regression hardening
- Product Reviews is resilient when `averageRating` is absent or malformed.
- Review eligibility and own-review lookups no longer require compound ordering indexes.
- Creator balance reconstruction no longer requires `creatorId + effectiveAt` composite ordering.
- Creator payout reads no longer require `creatorId + createdAt` composite ordering.
- Admin payout filtering avoids compound ordering dependencies.
- Admin notification reads no longer attempt collection subscriptions for sessions that are not Firestore-authorized platform moderators.
- PWA manifest icon metadata now uses valid absolute-safe URLs/types.
